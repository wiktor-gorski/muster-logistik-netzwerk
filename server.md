
# Server – Muster Logistik AG

## Netzwerkkonfiguration

Gerät: Server-PT
VLAN: 30

IP-Adresse: 192.168.30.10
Subnetzmaske: 255.255.255.0
Standardgateway: 192.168.30.1

## Aufgabe

Der Server stellt Dienste für das Unternehmen bereit.

Geplant ist, dass auf diesem Server die
Python-Lagerverwaltung ausgeführt wird.

## Warum eine feste IP-Adresse?

Der Server muss unter einer bekannten Adresse
erreichbar sein.

Deshalb erhält er eine statische IP-Adresse
und verwendet kein DHCP.
